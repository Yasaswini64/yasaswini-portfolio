# Yasaswini Chundru — Software Engineering Portfolio

Responsive, mobile-first static portfolio generated from the uploaded résumé.

## Run locally
Open `index.html` in a browser. The Resume/CV buttons download `resume.pdf`.

## Included UI and functionality
- Sticky navigation with mobile menu
- Light/dark theme toggle
- Responsive hero, skills, and custom project UI illustrations
- STAR-format project summaries based on resume facts, with no fabricated metrics
- Experience/milestone timeline with future internship clearly marked as upcoming
- Education and certification list
- Contact form that opens a prefilled email draft (no backend/server storage)

## Verified project links
- Hospital Management System: https://github.com/Yasaswini64/Hospital-management-system-
- Course Hub: https://github.com/Yasaswini64/Coursehub
- Data Structure Visualizer: linked to the GitHub profile because the exact repository URL was not explicitly named in the résumé.

## Publish
Upload the folder to Netlify or Vercel, or publish through GitHub Pages. The website files are ready; this package does not itself create a public hosted URL.

## Files
- index.html — content and structure
- style.css — responsive styling and light/dark theme
- script.js — theme toggle, mobile navigation, contact email draft
- resume.pdf — uploaded résumé
